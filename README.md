# WebShare — просмотр трансляции

Страница для зрителей: **https://lolendor.github.io/webshare/**

Введите код из приложения WebShare на Mac (или откройте ссылку `…/webshare/#КОД`) — изображение
и звук пойдут напрямую с компьютера в браузер по WebRTC (P2P, при необходимости через TURN).
Сигнальные сообщения проходят через публичные MQTT‑брокеры и зашифрованы AES‑256‑GCM ключом из кода.
